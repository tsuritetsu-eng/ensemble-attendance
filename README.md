# アンサンブル部 勤怠管理

GitHub Pagesで公開できる勤怠管理ブラウザアプリです。

- 部員管理：追加・編集・削除
- 勤怠入力：出勤・退勤・休憩
- 週次・月次集計
- スマートフォン対応
- Googleスプレッドシートを共有データベースとして利用可能

## Googleスプレッドシート連携

### 1. スプレッドシートを作成
Googleスプレッドシートを1つ作成し、**拡張機能 → Apps Script** を開きます。

### 2. Code.gs
リポジトリの `Code.gs` の内容をApps Scriptへ貼り付けます。

### 3. 初期設定
Apps Scriptの関数一覧から `setup` を1回実行します。自動的に「部員」「勤怠」シートと見出しが作成されます。

### 4. ウェブアプリとして公開
Apps Scriptで **デプロイ → 新しいデプロイ → ウェブアプリ** を選択します。
- 次のユーザーとして実行：自分
- アクセスできるユーザー：必要な範囲に設定
公開後に表示される **ウェブアプリURL** をコピーします。

### 5. GitHub側へURLを設定
`app.js` 冒頭の

```js
const API_URL='';
```

を

```js
const API_URL='あなたのApps ScriptウェブアプリURL';
```

に変更してGitHubへ反映します。

URL自体は秘密情報ではありません。**APIキーやGoogle認証情報をapp.jsへ書かないでください。**

### 6. 動作
API_URLを設定すると、部員・勤怠データはGoogleスプレッドシートへ保存され、別のスマホやPCから同じデータを読み込めます。API_URLが空の場合は従来どおり端末のlocalStorageを使用します。

### 注意
公開設定を「全員」にすると、URLを知っている人がAPIへアクセスできる構成になります。部員情報・勤怠情報を扱うため、実運用ではGoogleアカウント認証などのアクセス制御を追加することを推奨します。
